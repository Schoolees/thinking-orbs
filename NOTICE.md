# Attribution

This package is a framework-free adaptation of
[thinking-orbs](https://github.com/Jakubantalik/thinking-orbs) by Jakub
Antalik.

The original animation engine, state presets, and rendering profiles are used
under the MIT License included in this package.

The Schoolees adaptation replaces the React lifecycle with:

- a dependency-free `ThinkingOrb` JavaScript controller;
- a standards-based `<thinking-orb>` custom element;
- imperative state, speed, theme, pause, and cleanup APIs;
- reusable package builds and framework-neutral integration examples.
